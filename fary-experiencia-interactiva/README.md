# Para Fary ❤️🌪️ — experiencia interactiva

Sitio estático creado con HTML, CSS y JavaScript. Está listo para publicar en Vercel.

## Personalizar
- Edita el texto de la carta en `index.html`.
- Edita los detalles de la sorpresa en el bloque `.plan-card` de `index.html`.
- Agrega tus fotos a `public/photos/` con estos nombres:
  - `recuerdo-1.jpg`
  - `recuerdo-2.jpg`
  - `recuerdo-3.jpg`
  Los espacios de imagen muestran placeholders hasta que agregues las fotos.
- Cambia colores y tipografías en `public/style.css`.

## Publicar en Vercel
1. Descomprime el proyecto.
2. Sube la carpeta a un repositorio GitHub.
3. Entra a https://vercel.com/new e importa el repositorio.
4. Vercel detectará Vite. Deja el comando de build `npm run build` y directorio de salida `dist`.
5. Pulsa Deploy. Vercel te dará una URL pública.

## Crear el QR
Cuando la página esté publicada, copia la URL pública y crea un QR con un generador de QR confiable (por ejemplo, https://www.qrcode-monkey.com/).
Descarga el QR como PNG o SVG e imprímelo o compártelo.

## Nota
El contenido del plan final está intencionalmente presentado como una sorpresa genérica. Personaliza lugar y fecha cuando tengas decidido el plan. Revisa la experiencia desde el celular antes de compartirla.
